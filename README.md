# 💤 CS' LazyVim config

My nvim config based on the starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to their [documentation](https://lazyvim.github.io/installation) to get started.

## 🛠️ Installation

1. Make a backup of your current Neovim files:

   ```bash
   # required
   mv ~/.config/nvim{,.bak}

   # optional but recommended
   mv ~/.local/share/nvim{,.bak}
   mv ~/.local/state/nvim{,.bak}
   mv ~/.cache/nvim{,.bak}
   ```

1. Clone this config

   ```bash
   git clone https://github.com/cesalazar/lazyvim ~/.config/nvim
   ```

1. Start Neovim!

   ```bash
   nvim
   ```
